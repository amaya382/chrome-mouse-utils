<h1 align="center">🖱️ Mouse Utils Chrome Extension</h1>

<p align="center"><strong>右ボタンのジェスチャーと滑らかなホイールスクロールでブラウズ</strong></p>

Mouse Utils は plain JavaScript で書いた Manifest V3 の Chrome 拡張機能である。ビルドは不要で、リポジトリのディレクトリがそのまま拡張機能になる。

## ✨ Features

- **マウスジェスチャー** — 右ボタンを押したまま線を描いて、戻る、進む、再読み込み、タブを閉じる、閉じたタブを開き直す、隣のタブへ移る、を実行する。描いている間は軌跡と対応する動作を表示し、動かさずに右クリックすれば通常どおりコンテキストメニューが開く（macOS と Linux では右ダブルクリック）。動作ごとのジェスチャーはオプションで変えられる
- **滑らかなスクロール** — マウスホイールの 1 ノッチごとに、跳ばずに短いアニメーションでスクロールする。内側のスクロールペインもスクロールでき、地図のようにホイールを自分で使うページではページ側の動作を妨げない
- **邪魔をしない** — ツールバーの popup で機能ごとにオン / オフでき、URL の正規表現でサイトごとにジェスチャーを無効化できる

## 🚀 Quick Start

**前提**：Windows、macOS、Linux のデスクトップ版 Chrome

1. このリポジトリを clone する

   ```bash
   git clone https://github.com/amaya382/chrome-mouse-utils.git
   ```

2. `chrome://extensions/` を開く
3. 「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、clone したディレクトリを選ぶ

導入前から開いていたタブは再読み込みが要る。マウスジェスチャーは既定でオフなので、ツールバーの popup で「Mouse gestures」をオンにする。ページ上で右ボタンを押したまま左へドラッグし、左のタブに切り替われば動いている。

更新するときは `git pull` してから、`chrome://extensions/` の拡張機能カードにある再読み込みボタンを押す。

## 🖱️ Gestures

既定の割り当ては次のとおりで、すべてオンになっている。オプションではジェスチャーごとに割り当てを変えたりオフにしたりでき、形をプレビューで確かめられる。

| ジェスチャー | 動作 |
| --- | --- |
| ↑← | 戻る |
| ↑→ | 進む |
| ↑↓ | 再読み込み |
| ↓ | タブを閉じる |
| ↑ | 最後に閉じたタブを開き直す |
| ← | 左のタブへ移る |
| → | 右のタブへ移る |

タブの移動はウィンドウの端で反対側の端へ回り込む。20 px より短い動きは無視する。どの動作にも当てはまらないジェスチャーは何も実行しないが、コンテキストメニューは出さない。

## ⚙️ Configuration

ツールバーにある拡張機能のアイコンを押すと popup が開く。

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| Mouse gestures | オフ | 右ボタンのジェスチャーを認識する |
| Smooth scroll | オン | マウスホイールのスクロールをアニメーションさせる |

popup の「Options」を押すとオプションページが開く。

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| Gestures | [Gestures](#️-gestures) を参照 | 動作ごとのチェックボックスでジェスチャーをオン / オフし、← → ↑ ↓ から最大 3 ストロークを選ぶ |
| Scroll step | `120` | ホイール 1 ノッチでスクロールするピクセル数 |
| Duration | `200` | 1 回のスクロールのアニメーションにかけるミリ秒数 |
| Disabled URLs | (空) | 1 行に 1 つの正規表現。どれか 1 つでもページの URL に一致すると、マウスジェスチャーを無効にする。滑らかなスクロールには影響しない |

次の場合は保存できない。

- オンの動作にストロークを 1 つも選んでいない
- オンの 2 つの動作に同じジェスチャーを割り当てた
- 同じ方向が連続している (`←←` は `←` として認識される)
- 数値が正の整数でない
- 正規表現として解釈できない行がある

設定は `chrome.storage.sync` に保存され、同じ Chrome プロファイルにログインしたすべての端末に同期される。変更は、開いているタブにも再読み込みなしで反映される。

## 🔒 Permissions

- `storage` — 設定の保存と同期
- `sessions` — 最後に閉じたタブを開き直す
- すべてのサイトへのアクセス — 各ページでマウス操作を処理する

## 🔧 Troubleshooting

### ページでジェスチャーもスクロールも効かない

Chrome は `chrome://` のページと Chrome Web Store では拡張機能を動かさない。それ以外のページなら、導入後にタブを再読み込みしたかと、Disabled URLs にそのページと一致する行がないかを確かめる。

### macOS や Linux で右クリックしてもコンテキストメニューが開かない

macOS と Linux の Chrome は右ボタンを押した瞬間にコンテキストメニューを開く。この時点ではジェスチャーが続くかどうか判断できないため、ジェスチャーがオンの間はメニューを抑止する。メニューを開くには右ダブルクリックする。2 回目の押下ではジェスチャーを始めず、メニューをそのまま通す。

### 埋め込みコンテンツの上でジェスチャーや滑らかなスクロールが効かない

Mouse Utils はトップレベルのフレームでだけ動く。埋め込み動画や埋め込みドキュメントのような iframe の中では、ブラウザ標準の右クリックとスクロールになる。

### タッチパッドのスクロールが滑らかにならない

滑らかなスクロールの対象はマウスホイールのノッチだけである。タッチパッドはもともと滑らかにスクロールするので、その入力は Chrome に任せる。

## 🧪 Development

Node.js 18 以降でテストを実行する。

```bash
node --test
```

編集したら `chrome://extensions/` の拡張機能カードにある再読み込みボタンを押し、確かめるページも再読み込みする。
